# pylogs

[![License](https://img.shields.io/github/license/SimKDT/pylogs?label=License)](LICENSE)
![Code Size](https://img.shields.io/github/languages/code-size/SimKDT/pylogs?label=Code%20Size)

Python library of my own to provide console highlighting and logging features.

The color and echo modules are modified versions of the ones from [PZ Wiki Parser](https://github.com/Vaileasys/pz-wiki_parser).

## Installation

<details open>
<summary>PyPi</summary>

```bash
pip install pylogs
```
</details>

<details>
<summary>Git</summary>

```bash
pip install git+https://github.com/SimKDT/pylogs.git
```
</details>

<details>
<summary>Local</summary>

```bash
pip install .
```
</details>
